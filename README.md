## 🍓 它是干嘛的

想象一个场景：

> 剧下载在电脑里，人想窝在被子里用 iPad 看。
> 数据线？找不到。微信传？2GB 传到天亮。NAS？那是什么，能吃吗。

噗噗就是来解决这个的——

**右键视频 → 选择「噗~噗噗~~噗噗噗噗~~~~」→ 屏幕上出现一个二维码 → 手机扫一扫 → 开看。**

就这么简单。视频不离开你家，不用上传到任何地方。

## 🧁 三分钟上手

### 1️⃣ 安装

下载 **`pu-setup-full.exe`**，双击，一路「下一步」点到底。

这是**全自带版**：做菜的家伙（ffmpeg）已经打包好了，装完直接用，什么都不用操心。

> 电脑里早就装好 ffmpeg 的极客同学，可以选苗条一点的标准版 `pu-setup.exe`。
> 两个版本都有便携 zip：解压即用，不写注册表。

### 2️⃣ 右键任意视频

在视频文件上点**右键**，选 **「噗~噗噗~~噗噗噗噗~~~~」**。

等它眨眨眼（第一次要准备一下下），屏幕上会冒出一个二维码。

### 3️⃣ 手机扫码

用手机自带相机或浏览器扫一下——

**开始看吧，噗噗大王~** 👑

> 💡 右键**文件夹**也有效：会列出里面所有视频，手机上当追剧列表用。

## 🍬 常见问题

**Q：手机扫了没反应？**
看看手机和电脑是不是连着同一个 Wi-Fi。它俩必须在同一个家里（网络里的那种家）。

**Q：第一次用，它说要装 ffmpeg？**
那你下的准是标准版。照它说的做一次就好啦——或者干脆去换全自带版，连这一步都省了。

**Q：能看但卡？**
大文件第一次会先"备菜"（进度条会告诉你）。备好之后存在本地，下次秒开。

**Q：会不会把我的视频传到网上？**
不会。数据只在你家的路由器里打转，门都不出。

**Q：卸载干净吗？**
干净。从「设置 → 应用」里卸载，右键菜单、缓存、快捷方式全部带走，一片云彩都不留。
